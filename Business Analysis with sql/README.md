# Jirani Retail – SQL Data Analysis Project

## Project Overview
This project involves analysing a fictional Kenyan retail business, Jirani Retail, using MySQL. The objective is to explore sales performance, customer purchasing behaviour, product performance, and order trends to generate meaningful business insights.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Business Questions Answered
1. What is the total revenue generated from completed orders?
2. Which product generates the highest revenue?
3. Which product category generates the highest revenue?
4. Which sales channel generates the most revenue?
5. Which payment method is most commonly used?
6. Which five cities generate the highest revenue?
7. Which customers have placed more than one completed order?
8. What percentage of orders are cancelled or returned?

## Key Findings
- Total revenue from completed orders was **KES 37,792,479.42**.
- Power Bank was the highest-revenue product.
- Fashion was the highest-revenue product category.
- Retail Store generated the highest revenue among the sales channels.
- Cash was the most commonly used payment method.
- Mombasa recorded the highest revenue among the five leading cities.
- 212 customers had placed more than one completed order.
- 33.33% of all orders were cancelled or returned.

## Project Objective
The project demonstrates my ability to use SQL to query relational datasets, perform data analysis, identify business trends, and communicate findings that can support data-driven decision-making.
