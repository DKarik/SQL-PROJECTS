# SQL Sales Data Cleaning Project

## Overview
This project focuses on cleaning and validating a sales dataset using MySQL. The goal is to improve data quality, consistency, and reliability before further analysis.

## Objectives
- Inspect and profile raw sales data.
- Identify and remove exact duplicates.
- Standardize inconsistent text categories.
- Parse and validate date fields.
- Investigate and handle missing values.
- Identify logical errors, invalid values, and outliers.
- Validate the cleaned dataset.

## Workflow
The project follows a structured data-cleaning process, from raw-data inspection through final validation. SQL scripts and documentation record the cleaning steps and the reasoning behind key decisions.

## Project Status
Missing-value investigation and standardization have been documented. Additional data-quality checks and final validation will be completed as the project progresses.

## Key Learning Outcomes
- Writing SQL queries to inspect and clean data.
- Using conditional logic to identify data-quality issues.
- Making evidence-based decisions about missing values.
- Documenting data transformations for reproducibility.
